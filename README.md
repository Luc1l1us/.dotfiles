# .dotfiles
My dotfiles for both Windows and Linux

<p> There are two themes in the repo which are: BlacknWhite and Catpuccin </p>
<p> However, it will soon be combined into one theme, which encompasses all existing themes and any themes that are to be made in the near future. </p>

# Installation Guide

For Catppuccin
```
git clone https://github.com/Luc1l1us/.dotfiles.git
cd ~/.dotfiles/Catppuccin
chmod +x ~/.set-hyper.sh
./set-hypr.sh
```

OR
```
git clone https://github.com/Luc1l1us/.dotfiles.git
cd ~/.dotfiles/BlacknWhite
chmod +x ~/.set-bw.sh
./set-bw.sh
```
